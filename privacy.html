سياسة الخصوصية

توضح هذه الصفحة بصورة مبسطة كيفية التعامل مع المعلومات عند زيارة موقع مرتكز أو التواصل عبر البريد الإلكتروني.

1. نطاق الموقع

الموقع الحالي موقع تعريفي ومعرفي مستضاف عبر GitHub Pages. لا توجد في النسخة الحالية حسابات مستخدمين أو بوابة عملاء أو رفع مستندات عبر الموقع.

2. المعلومات التي تقدمها طوعًا

إذا تواصلت عبر البريد الإلكتروني، فقد تصل إلينا المعلومات التي تختار إرسالها مثل الاسم وبيانات التواصل ومحتوى الرسالة. يُنصح بعدم إرسال مستندات أو بيانات حساسة قبل الاتفاق على قناة مناسبة وآمنة للتعامل معها.

3. التحليلات والتتبع

النسخة الحالية من الصفحة الرئيسية لا تستخدم معرّف Google Analytics أو نظام تحليلات تسويقي مفعّل من طرفنا. قد تسجل جهة الاستضافة أو مزودو الموارد الخارجية بيانات تقنية أساسية وفق سياساتهم الخاصة.

4. الموارد الخارجية

يستخدم الموقع حاليًا موارد من Google Fonts وcdnjs لعرض الخطوط والأيقونات. عند تحميل هذه الموارد قد يتصل المتصفح بهذه الجهات وفق سياسات الخصوصية الخاصة بها.

5. مشاركة المعلومات

لا نبيع بيانات الزوار. وإذا تطلب مشروع مستقبلي استخدام مزود خدمة أو منصة خارجية فسيتم تحديث هذه السياسة بما يعكس طريقة الاستخدام الفعلية.

6. التحديثات المستقبلية

عند إضافة نماذج تواصل متقدمة، أدوات تقييم، حسابات مستخدمين، تحليلات، أو خدمات رفع ملفات، ستتم مراجعة السياسة قبل تفعيل تلك الخصائص.

7. التواصل
